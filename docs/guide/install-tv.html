Перед началом

📺 Телевизор

Samsung (Tizen), LG (webOS), Android TV / Google TV, Amazon Fire TV — подойдёт почти любой «умный» телевизор с интернетом.

📱 Телефон

С ним вы подключите телевизор и сможете отправлять на него фильмы. Нужны логин и пароль Cineko.

1 · Установите Media Station X

Это бесплатное приложение-«пульт запуска», через которое открывается Cineko.

ТелевизорГде найти
SamsungКнопка Home → Apps (Приложения) → поиск → Media Station X → Установить
LGLG Content Store → поиск → Media Station X → Установить
Android TV / Google TVGoogle Play → Media Station X → Установить
Fire TVAmazon Appstore → Media Station X → Get
iPadApp Store → Media Station X → Загрузить. Адрес — тот же (шаг 2). На iPad откроется версия для пальцев с обычной клавиатурой: вместо шага 3 один раз войдите логином и паролем.

2 · Укажите наш адрес

Откройте Media Station X. Меню этого приложения на английском:

  1. Шестерёнка Settings → Start Parameter → Setup.
  2. Введите адрес вашего сервера Cineko, например {{SITE}} (адрес даст администратор).
  3. Включите значок замка 🔒 (защищённое соединение HTTPS).
  4. Нажмите OK / Confirm и перезапустите Media Station X.

После перезапуска появится меню с кнопкой Cineko (и другими, если администратор их добавил). Настройка запоминается — повторять не нужно.

Подключение

3 · Подключите телевизор к своему аккаунту

Нажмите Cineko. На экране появятся QR-код и короткий код вида K7QM-2XPD.

Способ 1 · QR-код

Войдите в Cineko на телефоне ({{SITE}}), наведите камеру на QR-код, проверьте, что код совпадает, задайте название («Гостиная») и нажмите Подключить ТВ.

Способ 2 · код вручную

На телефоне или компьютере откройте {{SITE}}/pair (или Устройства → Подключить ТВ) и введите код с экрана телевизора.

Через пару секунд телевизор подключится сам и спросит «Кто смотрит?» — выберите профиль стрелками и OK. В следующий раз Cineko откроется сразу — подключать заново не нужно.

4 · Смотрите

◀ ▲ ▼ ▶ OKПеремещение и выбор. Слева — меню: поиск, главная, ТВ, видео, фильмы, сериалы, настройки.
НазадРовно один шаг назад. На главной — дважды, чтобы выйти.
⏯ на карточкеСразу включить лучший вариант раздачи.
СмотретьCineko сам подберёт раздачу под ваш телевизор. Кнопка ☰ рядом — выбрать самому: качество, озвучка, размер, число сидов.
Долгое OK на раздаче«Смотреть в…» — выбрать плеер: Cineko, плеер Media Station X (если файл не играет — попробуйте его) или внешнее приложение на Android.

Телефон — это пульт. На странице фильма нажмите Смотреть на ТВ — фильм откроется на телевизоре. Нажмите на телевизор на главной телефона — откроется пульт: пауза, перемотка, следующая серия, звук и субтитры.

Если что-то не так

Частые вопросы

ПроблемаЧто сделать
Не появилось меню с кнопкой CinekoПроверьте адрес {{SITE}} и замок 🔒 в Start Parameter, затем полностью закройте и снова откройте Media Station X.
QR-код не сканируетсяВведите код вручную на {{SITE}}/pair.
«Профилей пока нет»Создайте профиль на телефоне: Профили → Добавить профиль. Телевизор обновится сам.
Видео не запускается или нет звукаНекоторые телевизоры не умеют HEVC, DTS или MKV. Выберите другую раздачу (лучше H.264 / AAC) или «Смотреть в… → плеер Media Station X».
Долго «Готовим поток…»У раздачи мало сидов. Подождите минуту или выберите вариант с бо́льшим числом сидов.
На телевизоре «Переподключение…»Проверьте интернет; Cineko подключится сама, как только сеть вернётся.
Старый телевизор подтормаживаетВ Настройки выберите оформление «Кинозал», выключите «Анимация при запуске» и поставьте пресет «Слабый ТВ / медленный интернет».
На iPad нужна версия для ТВАватар → «Версия для ТВ». Назад в MSX — «Вернуться в Media Station X».
Нужно отключить телевизорНа телефоне: Устройства → Отключить. Чтобы подключить снова — шаг 3.

Без Media Station X

Откройте браузер телевизора и перейдите по адресу {{SITE}}/tv. Дальше — как в шаге 3.

Приложение на телефон

iPhone: Safari → {{SITE}} → «Поделиться» → «На экран „Домой“».
Android: Chrome → {{SITE}} → меню ⋮ → «Установить приложение».

Подробно обо всём — в полной инструкции «Как пользоваться Cineko»: на телефоне Настройки → Инструкции.
